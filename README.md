# 📌 Team 4 – AI Meeting Minutes Generator

An AI-powered system that converts meeting transcripts (text or audio) into structured meeting minutes. It automatically extracts important information and presents it in an organized format.

## 🔹 Features
- Accepts meeting transcript (text or audio)
- Generates key discussion points
- Identifies action items
- Extracts responsible persons
- Detects deadlines
- Outputs results in bullet points or table format
